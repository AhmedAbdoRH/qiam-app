# Qiam App 📱

تطبيق **قيام** — تطبيق موبايل (Expo / React Native) للاتزان النفسي والروحي:
الحوار الذاتي، القيم، التقويم، الأسماء الإلهية، العادات اليومية، والتقارير.

## البنية

| المجلد | الوصف |
|---|---|
| `app/` | شاشات التطبيق (expo-router) — الأساس |
| `src/` | المكوّنات والسياقات والخدمات — الأساس |
| `assets/` | الأيقونات والصور |
| `supabase/` | ملفات قاعدة البيانات المشتركة (migrations) |
| `web/` | نسخة الويب القديمة — **مرجع فقط**، ليست جزءًا من التطبيق |

## التشغيل

```sh
npm install
npx expo start
```

انسخ `.env.example` إلى `.env` وعبّئ مفاتيح Supabase:

```sh
cp .env.example .env
```

## البناء للأندرويد

```sh
npm run android        # تشغيل على جهاز/محاكي
npm run build:apk      # بناء APK عبر EAS (preview)
npm run build:aab      # بناء AAB للنشر (production)
```

## ملاحظة عن `web/`

مجلد `web/` يحتفظ بنسخة الويب (Vite + React) كمرجع لمنطق الأعمال والتقارير فقط.
التطوير الأساسي يتم على التطبيق في جذر المستودع.
